# Android wrapper (APK) changelog

Changelog of the installable Android wrapper for [Astronomical Clock](https://AstronomicalClock.eu/).

The Android wrapper and the web app use separate versioning. The version numbers in this file refer only to the Android wrapper. The wrapper includes the PWA web app, while the web app itself has its own version number and is updated independently without requiring a new APK release. – `anvXXX` = android.numeric_version

---

## [anv2] - 2026-09-11

### Changed
- TWA start mode changed from `standalone` to `fullscreen`

## [anv1] - 2026-08-13

### Added
- Initial baseline version of the Android wrapper

---

> **Hint:** Instead of installing the APK, the PWA can also be installed by adding it to the [Home Screen](https://github.com/gaxmann/gordonssunclock/wiki/Web-app). This provides offline use, a Home Screen icon, full-screen display and automatic updates without installing an APK.
